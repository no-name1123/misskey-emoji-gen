# misskey-emoji-gen

Misskey のカスタム絵文字に使う文字画像(文字絵文字)を、ブラウザだけで作成・保存できる Web サイトです。

- 文字・フォント・色・縁取り・影・動きを選び、PNG / APNG / GIF で保存します
- 入力した文字や読み込んだフォントは、利用者の端末の中だけで処理し、外部には送信しません
- GitHub Pages で公開します
